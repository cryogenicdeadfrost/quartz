## v1.0.0 (2026-11-14)

- Initial release of `quartz`.
- `Quartz.Signal`: Fine-grained reactive signals (`use_state`, `use_memo`, `use_effect`, `batch`, `!~`, `<~`).
- `Quartz.Style` & `Palette`: Type-safe Tailwind-style CSS rules with automatic `:hover`, `:focus`, `.dark`, and `@media` breakpoint compilation.
- `Quartz.Dom`: Full HTML5 & inline SVG builder with reactive `rx`, `show`, `each`, and 1-line two-way input bindings.
- `Quartz.Router` & `Quartz.Form`: SPA/multi-page URL router with `:param` extraction and composable form validators.
- `Quartz.Components`: Batteries-included UI kit (`card`, `stat_card`, `badge`, `btn`, `alert`, `modal`, `tabs`, `navbar`, `data_table`, `sparkline`, `bar_chart`).
- `Quartz.Server` & `Quartz.Tui`: Zero-npm HTTP LiveView server, static multi-page HTML/CSS exporter, and pure-OCaml Flexbox terminal renderer.
